# 🍌 Capitaine Banane

Jeu éducatif pour enfants de 5 à 7 ans : le Capitaine Banane, explorateur drôle et bienveillant, accompagne l'enfant dans une aventure sur une île mystérieuse.

## Ce que contient le jeu
- Consignes **lues à voix haute** (synthèse vocale du navigateur, bouton 🔊 pour réécouter)
- Plus de 20 missions de difficulté croissante : énigmes, compter, ballons, memory, intrus, suites logiques, coloriage, lecture (niveau CP), alphabet, syllabes, rimes, labyrinthe, attrape-bananes, additions, cherche et trouve, course de voitures, rébus…
- 3 essais par question, puis le capitaine donne la réponse (pas de frustration)
- Bananes, étoiles, confettis et sons à chaque réussite
- Épreuve ultime puis coffre au trésor animé
- Espace parent, pause conseillée après 15 minutes, bouton « Recommencer »
- Partie gratuite (4 premières missions) + partie premium débloquée par un code

## Jouer
Ouvrir le fichier `index.html` dans un navigateur (Chrome ou Safari), ou utiliser le lien GitHub Pages du projet.

## Changer le code premium
Dans `index.html`, chercher `CODE='BANANE5'` et remplacer BANANE5 par le code de ton choix.

## Remarques
- Aucune donnée n'est envoyée : la progression est enregistrée uniquement dans le navigateur de l'appareil.
- Pour que la voix fonctionne : son activé, téléphone pas en mode silencieux, voix française installée.
